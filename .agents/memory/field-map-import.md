---
name: Field map import rules
description: User requirements for interpreting field numbers and crop names in uploaded KML boundaries.
---

Номера полей в загруженных KML являются действительными. Культуры в названиях файлов не отмечать.

**Why:** Пользователь прямо подтвердил номера и запретил использовать культуры из названий файлов при передаче контуров для карты полей.

**How to apply:** Использовать номер для привязки контура к справочнику соответствующего хозяйства. Не менять севооборот и не подписывать культуру по имени KML. Если номер или хозяйство не определены, уточнить их, а не присваивать по порядку файлов.

Пользователь уточнил: все переданные контуры относятся к «АПК Арыстан Grain», а файл «Ячмень» обозначает самостоятельное поле №1/1, не поле №1.

**Why:** Прямой ответ пользователя при привязке файлов к справочнику.

**How to apply:** Не объединять №1 и №1/1 и не выводить культуру для №1/1 из имени файла.

Импорт контура не заменяет уже введённую учётную площадь и не меняет историю поля. Площадь контура показывается отдельно; у новых полей первоначальная площадь рассчитывается по геометрии с явным примечанием.

**Why:** Контуры некоторых полей существенно отличаются по площади от ранее внесённого справочника; разрешения менять производственные данные пользователь не давал.

**How to apply:** При следующих импортах сохранять существующие площади, сезоны, операции и идентификаторы. Автоматический начальный импорт должен быть однократным, чтобы после перезапуска не восстанавливались старые номера, которые позднее изменил сотрудник.
