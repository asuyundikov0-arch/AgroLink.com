---
name: Field map import rules
description: User requirements for interpreting field numbers and crop names in uploaded KML boundaries.
---

Номера полей в загруженных KML являются действительными. Культуры в названиях файлов не отмечать.

**Why:** Пользователь прямо подтвердил номера и запретил использовать культуры из названий файлов при передаче контуров для карты полей.

**How to apply:** Использовать номер для привязки контура к справочнику соответствующего хозяйства. Не менять севооборот и не подписывать культуру по имени KML. Если номер или хозяйство не определены, уточнить их, а не присваивать по порядку файлов.
