---
name: Application visual direction
description: Predominantly black-and-white interface with the user's AgroLink field photograph as a shared background.
---

Пользователь попросил возможность выбирать между чёрно-белой темой (преимущественно чёрной) и бело-синей (преимущественно белой). Переданное изображение AgroLink с полем остаётся общим задним фоном личных кабинетов и отделов.

**Why:** Прямое указание пользователя по оформлению всего приложения, а не отдельного экрана.

**How to apply:** Новые разделы и диалоги должны поддерживать обе темы и читаемый контраст. Сохранять общий фон во всех кабинетах и выбранную пользователем тему.
