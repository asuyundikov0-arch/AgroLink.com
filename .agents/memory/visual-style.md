---
name: Application visual direction
description: Predominantly black-and-white interface with the user's AgroLink field photograph as a shared background.
---

Пользователь попросил заменить голубое и белое оформление на чёрно-белое, преимущественно чёрное, и использовать переданное изображение AgroLink с полем как задний фон личных кабинетов и всех отделов.

**Why:** Прямое указание пользователя по оформлению всего приложения, а не отдельного экрана.

**How to apply:** Новые разделы и диалоги должны поддерживать тёмное оформление и читаемый контраст. Сохранять общий фон во всех кабинетах; не возвращать голубую тему или сплошные белые рабочие панели без нового указания.
