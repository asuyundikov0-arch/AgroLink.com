# Предложение по начислению зарплаты

Изолированная демонстрация для обсуждения с пользователем. Не является
действующим отделом кадров и не меняет основной сайт AgroLink operation.
Данные сотрудников и начислений вымышлены. Все действия выполняются только
в памяти страницы и сбрасываются при перезагрузке.

## Что сохраняется в предложении

- Главный агроном задаёт предполагаемую расценку в плане; это не начисление.
- Диспетчер заполняет фактические работы и расценки по полям и перевозкам.
- Отдел кадров подтверждает ежедневные наряды перед накоплением зарплаты.
- Реестр содержит начисления, а не банковские выплаты.

## Что предлагается добавить

- Табель разнорабочих с дневной или часовой оплатой.
- Расчёт окладной части специалистов по норме и фактически отработанному
  времени. Норма 22 дня в демонстрации — условный пример, не утверждение
  о производственном календаре.
- Общий реестр по сотрудникам с источниками и формулами расчёта.

Отпуска, больничные, доплаты, налоги и удержания требуют отдельных правил.
Автоматическое сложение оклада и сдельной оплаты не предполагается:
смешанная оплата должна быть прямо предусмотрена условиями сотрудника.

Реальные роли, доступы, хранение, кадровые документы, календарь, распределение
повременных затрат по полям и перенос в основной сайт здесь не реализуются.
Подключать это предложение к рабочей системе можно только после одобрения.
